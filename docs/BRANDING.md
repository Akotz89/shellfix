# Shellfix Branding

## Primary Title

Shellfix: Stop PowerShell From Breaking AI Agent Commands

## Short Description

A Windows command shim that reduces quoting, WSL routing, stderr, ANSI, UTF-8, and path issues in PowerShell-based coding agent workflows.

## Social Preview

Use `assets/shellfix-social-preview.png` for LinkedIn posts and GitHub's repository social preview.

Use `assets/shellfix-wordmark.svg` as the compact README/header brand mark. Do not place the full social preview bitmap at the top of the README; it is too large for GitHub's document layout.

GitHub does not expose custom repository social preview image updates through the standard `gh` CLI workflow. To set it manually:

1. Open the repository on GitHub.
2. Go to Settings.
3. In Social preview, upload `assets/shellfix-social-preview.png`.
4. Save the repository settings.

## Tone

Use direct operator-facing language. Avoid hype, chat-transcript wording, and claims that are not backed by tests, release artifacts, or manual verification notes.
